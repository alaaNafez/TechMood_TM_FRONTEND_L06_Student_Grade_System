## Project Name

Student Grade System

## Technologies

HTML5 | CSS3 | JavaScript

## Description

A simple web the app takes a student's name and grade through an interactive form, evaluates the performance, and displays the result directly on the page.

## Features

- Simple & Clean UI
- Purple Color Theme
- Input Fields for Student Name & Grade
- Grade Evaluation Logic (Excellent, Very Good, Good, Pass, Fail)
- Interactive "Check Grade" Button
- Result Displayed Instantly on the Page
